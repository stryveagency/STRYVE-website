PASSO 5: PRESERVAR ANIMAÇÕES E INTERATIVIDADE
- Parallax no Hero: use onMouseMove e transform: perspective
- Contadores animados em Resultados: use useEffect + incrementar valor até o alvo
- Timeline em Método: use CSS animations ou Framer Motion
- Smooth scroll de menu: <a href="#manifesto" onClick={scrollToElement}>
- Hovers em cartões: use Tailwind hover:scale-105 ou similar
- Todos os efeitos devem ser suaves e não afetar performance

PASSO 6: CORES E TIPOGRAFIA (CRÍTICO)
Cores principais (do STRYVE Landing.html):
- Fundo: #000000 (preto profundo)
- Destaque teal: #2EE6B8 (ou próximo)
- Texto principal: #FFFFFF (branco)
- Texto secundário: #999999 (cinza claro)

Tipografia (confirmar no HTML):
- Headlines: font-family deve ser condensada/bold, font-size grande
- Corpo: font-family serifada ou sans-serif conforme HTML
- Destaques: possível cursiva serifada em pontos específicos

PASSO 7: TESTAR E COMPARAR
- Execute: npm run dev
- Abra http://localhost:5173 (ou porta configurada)
- Tire screenshots de cada seção scrollando de cima a baixo
- Compare lado a lado com: cabeçalho.png, sessão-hero.png, ... rodapé.png, layout-completo.png

PASSO 8: CORREÇÕES ITERATIVAS
- Para cada diferença encontrada (cor não bate, margin está menor, font-size errado):
  * Abra o componente correspondente
  * Ajuste o valor (ex: padding-x muda de 8 para 12, cor muda de #2EE6B8 para #2EE6BA)
  * Salve e veja a mudança ao vivo no navegador
  * Tire novo screenshot e compare
  * Repita até bater 100% com o original
